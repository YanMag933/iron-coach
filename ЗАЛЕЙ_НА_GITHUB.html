Залить приложение на GitHub за 7 кликов

Я (ассистент) не могу войти в твой GitHub за тебя — у сайта нет доступа к твоему паролю. Ниже самый простой путь через сайт, без команд.

Шаг 1. Войди

Открой на компьютере:

Открыть вход в GitHub

Если аккаунта нет — нажми Create an account и создай.

Шаг 2. Создай пустую папку на сайте

Создать новый репозиторий
  1. В поле Repository name напиши: iron-coach
  2. Поставь точку на Public
  3. Не ставь галочки README / .gitignore / license
  4. Нажми зелёную кнопку Create repository

Шаг 3. Залей файлы приложения

  1. На странице нового репозитория нажми ссылку uploading an existing file
  2. Открой проводник Windows: папка Desktop\ЯН\fitness-coach-pwa
  3. Выдели всё внутри (Ctrl+A): папки css, js и файлы index.html, manifest.json, sw.js, icon.svg и остальные
  4. Перетащи их в окно браузера GitHub
  5. Внизу нажми зелёную Commit changes

Важно: заливай содержимое папки fitness-coach-pwa, а не саму папку целиком как один пустой контейнер. В корне репозитория должен лежать именно index.html.

Шаг 4. Включи сайт (Pages)

  1. В репозитории сверху нажми Settings
  2. Слева найди Pages
  3. Branch: выбери main, папка / (root)
  4. Save
  5. Подожди 1–2 минуты и обнови страницу

Шаг 5. Ссылка для телефона

Ссылка будет такой (подставь свой ник GitHub):

https://ТВОЙ_НИК.github.io/iron-coach/

Её же покажет GitHub в Settings → Pages зелёной плашкой.

Открой эту ссылку на телефоне → Safari/Chrome → «На экран Домой».

Если снова 404

  • Подожди ещё 2–3 минуты после Save в Pages
  • Проверь, что в репозитории в корне есть index.html (не внутри подпапки)
  • Открывай именно ….github.io/iron-coach/, а не страницу репозитория github.com/…

Когда получишь ссылку — пришли её сюда в чат, проверю что всё открывается.
