IRON COACH — как запустить на телефоне
======================================

Есть 2 пути. Для «как настоящее приложение с иконкой и офлайном»
нужен путь А (HTTPS). Путь Б — быстрый просмотр по Wi‑Fi.


══════════════════════════════════════
ПУТЬ А (рекомендую): постоянная ссылка
через GitHub Pages — бесплатно
══════════════════════════════════════

Подготовка на компьютере
------------------------
1. Зарегистрируйся / войди на https://github.com
2. Установи GitHub Desktop (проще) ИЛИ пользуйся сайтом GitHub.

Вариант через сайт GitHub (без программ)
----------------------------------------
1. Открой https://github.com/new
2. Repository name: iron-coach (или любое имя латиницей)
3. Public → Create repository
4. На странице репозитория нажми «uploading an existing file»
5. Перетащи ВСЕ файлы из папки:
   Desktop\ЯН\fitness-coach-pwa
   (index.html, css, js, sw.js, manifest.json, icon.svg и т.д.)
   Не нужно заливать только вложенную пустую мусорку — нужны сами файлы приложения.
6. Commit changes

Включи GitHub Pages
-------------------
1. В репозитории: Settings → Pages
2. Branch: main (или master), папка: / (root)
3. Save
4. Подожди 1–2 минуты
5. Ссылка будет вида:
   https://ТВОЙ_НИК.github.io/iron-coach/
   (точный адрес покажет Settings → Pages)

Открой на телефоне и «установи»
-------------------------------
1. На телефоне открой эту https-ссылку
2. Пройди анкету тренера

ANDROID (Chrome):
1. Открой ссылку в Chrome
2. Меню ⋮ → «Установить приложение»
   или «Добавить на главный экран»
3. Подтверди
4. На рабочем столе появится иконка IRON COACH
5. Открывай как обычное приложение (без адресной строки)

IPHONE / IPAD (только Safari):
1. Открой ссылку в Safari (не в Chrome/Telegram)
2. Кнопка «Поделиться» (квадрат со стрелкой вверх)
3. «На экран „Домой“» / Add to Home Screen
4. Добавить
5. Открывай иконку с домашнего экрана

Готово: приложение работает на телефоне само,
данные тренировок хранятся на телефоне.


══════════════════════════════════════
ПУТЬ Б: быстро через Wi‑Fi с компьютера
(для теста, не идеально для установки)
══════════════════════════════════════

Важно: по адресу http://192.168... телефон откроет сайт,
но «Установить как PWA» и полный офлайн часто НЕ работают
(нужен HTTPS). Для постоянной установки используй путь А.

1. Компьютер и телефон — в одной Wi‑Fi сети
   (не раздача с телефона, если IP «пляшет» — лучше домашний роутер)

2. На ПК дважды кликни файл ЗАПУСК.bat
   в папке fitness-coach-pwa
   Окно сервера оставь открытым (не закрывай).

3. Узнай IP компьютера:
   - Win + R → cmd → Enter
   - введи: ipconfig
   - найди «IPv4-адрес», обычно вида 192.168.x.x
   Пример: 192.168.43.164

4. На телефоне в браузере открой:
   http://IP:8765
   Пример: http://192.168.43.164:8765

5. Если не открывается:
   - проверь, что ЗАПУСК.bat ещё запущен
   - отключи VPN на ПК/телефоне
   - Windows может спросить разрешение брандмауэра — разреши
   - попробуй другой браузер (Chrome / Safari)


══════════════════════════════════════
Что делать после установки
══════════════════════════════════════
1. Заполни анкету (вес, подтягивания, дни в неделю)
2. Вкладка «Сегодня» → выбери день → «Начать тренировку»
3. На упражнении можно открыть «Техника» — там мышцы и подсказки
4. Журнал сохраняется на этом телефоне
   (если очистишь данные сайта/приложения — журнал пропадёт)


══════════════════════════════════════
Частые проблемы
══════════════════════════════════════
• На iPhone ставится только из Safari
• «Установить» не видно → открой именно https://... (путь А)
• Белый/чёрный экран → обнови страницу, проверь что залиты папки css и js
• Python не найден при ЗАПУСК.bat → установи Python
  с https://www.python.org/downloads/ и галкой «Add to PATH»
  или используй путь А без локального сервера


Файл лежит рядом с приложением:
